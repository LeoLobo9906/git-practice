# Parallel Computing

## Article

[Introduction to Parallel Computing - Lawrence Livermore National Laboratory](https://hpc.llnl.gov/documentation/tutorials/introduction-parallel-computing-tutorial)

I found this article interesting because I am currently learning about parallel computing and how computers can use multiple processors to solve problems at the same time. Before learning about this, I mostly thought about programs as a sequence of instructions being executed one after another. Parallel computing changes that by breaking a problem into smaller parts that can potentially be worked on simultaneously.

Something interesting I found was that having more processors does not automatically make a program faster. The software still has to be designed so that the work can actually be divided between them, while dealing with things like communication and dependencies between tasks. I think thats what I have found most interesting so far the relationship between software and hardware.
